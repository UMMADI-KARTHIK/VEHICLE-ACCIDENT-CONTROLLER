Vehicle Accident Detection and Control System

This project is a microcontroller-based system designed to **detect vehicle accidents** and **send emergency alerts** using GSM and GPS modules. It can be implemented in cars or bikes for safety monitoring and automated emergency response.

---

## 📌 Features

- Accident detection using accelerometer (e.g., MPU6050 or ADXL345)
- Real-time location tracking using GPS module (e.g., NEO-6M)
- Alert message sent to emergency contacts via GSM (SIM800L/SIM900)
- Optional buzzer or display for local alert
- Low power consumption, suitable for vehicle use

---

## 🛠️ Components Used

| Component             | Description                            |
|----------------------|----------------------------------------|
| Arduino UNO/Nano     | Microcontroller                        |
| MPU6050 / ADXL345    | Accelerometer for shock/tilt detection |
| GPS Module (NEO-6M)  | Location tracking                      |
| GSM Module (SIM800L) | Message alert system                   |
| Buzzer (Optional)    | Sound alert                            |
| 16x2 LCD (Optional)  | Display location or status             |
| Power Supply         | 5V Battery or Adapter
